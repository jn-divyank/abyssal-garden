# Abyssal Garden

A procedural WebGPU underwater scene in one self-contained `index.html` (no engine, no texture or model files).

- Live: https://jn-divyank.github.io/abyssal-garden/
- Renders and clips: https://jn-divyank.github.io/abyssal-garden/gallery.html

Desktop controls: click, then WASD, mouse, Q/E, Shift; F starts the guided swim; 1-6 jump to fixed views. On a phone: drag to look, tap to start or stop the guided swim.
